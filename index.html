ADMIN
Study Rooms の使い方

最初にホーム画面へ追加すると、次回からアイコンをタップしてすぐに開けます。基本操作もここで確認できます。

Safariからホーム画面に追加する

ホーム画面に追加すると、Study Roomsをアイコンからすぐに開けます。iOS 26では「ウェブアプリとして開く」が初期状態でオンになっています。

← 左右にスワイプして手順を見る →
  1. iPhoneのSafariでStudy Roomsを開きます。
  2. 画面右下のページメニュー「•••」をタップして「共有」を選びます。タブレイアウトが「上」「下」の場合は、共有ボタンを直接タップします。
  3. 共有シートの「その他」をタップし、「ホーム画面に追加」を選びます。見つからないときは下へスクロールします。
  4. 「ウェブアプリとして開く」がオンになっていることを確認します。通常は最初からオンです。
  5. 右上の「追加」をタップすると、ホーム画面にStudy Roomsのアイコンが追加されます。
「ホーム画面に追加」が見つからない場合
共有メニューの一番下までスクロールし、「アクションを編集」から「ホーム画面に追加」を追加してください。

Apple公式：Safariでウェブサイトをアプリにする

02 / FIND A ROOM

自習室・利用時間を確認する

上部の「AVAILABLE NOW」には、現在利用できる教室が表示されます。「NEXT AVAILABLE」は、次に利用可能になる教室の目安です。

◷
現在の状況今使える教室
→
次の利用予定次に始まる教室
▤
教室一覧日付を選んで確認

「教室一覧」右側の日付メニューを切り替えると、その日の予定を確認できます。今日の予定では、利用可能・開始前の表示も確認できます。

03 / CROWD STATUS

混雑状況を評価・確認する

現在利用時間内の教室カードをタップすると、評価用の丸が表示されます。状態に近い色を選んでください。

評価はほかのログインユーザーにも共有されます。表示時刻は、その評価が保存された時点です。評価できるのは教室の利用時間内です。

04 / DATA UPDATE

自習室情報を更新する

河合塾のマイページで自習室情報を表示し、設定済みのショートカットを実行してデータを取り込みます。更新後、表示内容と最終更新時刻を確認してください。

ショートカットが使えない場合は、ページ下部の「JSONを手動で読み込む」から、取得済みのJSONを貼り付けて読み込むこともできます。

表示内容は変更される場合があります。実際に利用する前に、校舎の掲示板などで最新情報を確認してください。

ADMIN

管理者専用機能

管理者には、画面右上の「≡」からADMINメニューが開きます。JSON編集、バックアップ、共有解除、テスターモード（仮JSONの試し表示を含む）が使えます。一般ユーザーには表示されません。テスターモードのデータは自分の画面内だけで使われ、実データには保存されません。

画面イラストは、iOS 26以降のSafari（コンパクト表示）の画面をもとにした図です。端末やタブレイアウトの設定によって、ボタンの位置や名前が少し異なる場合があります。
